# V-ICU | Virtual Cardiac ICU Monitor

Симулятор моніторингу пацієнтів після кардіохірургічних операцій у реальному часі з розумними алертами.

## Стек

- **React 19** + **TypeScript**
- **Vite** (збірник)
- **TailwindCSS v4**
- **Recharts** (графіки вітальних знаків)
- **Motion/React** (анімації)

## Функціонал

- Симуляція вітальних знаків у реальному часі (ЧСС, АТ, SpO2, температура) — оновлення кожні 1.5 сек
- Кольорове маркування статусу: STABLE / WARNING / CRITICAL
- Система алертів з індивідуальними порогами для кожного пацієнта
- ECG та ABP графіки в реальному часі
- Додавання/редагування профілів пацієнтів
- Налаштування індивідуальних порогів моніторингу

## Запуск локально

**Вимоги:** Node.js 18+

```bash
npm install
npm run dev
```

Відкрийте [http://localhost:3000](http://localhost:3000)

## Збірка

```bash
npm run build
```

Результат у папці `dist/`.
